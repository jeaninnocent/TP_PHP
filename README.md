# 🎓 TP PHP/MySQL – Gestion des Étudiants

## Description

Ce projet est une application web développée en **PHP et MySQL** permettant de gérer des étudiants et des filières.

Il a été réalisé dans le cadre d’un **travail pratique (TP)** à l’ESATIC.

---

## 🚀 Fonctionnalités

### 👨‍🎓 Gestion des étudiants

- ✅ Ajouter un étudiant
- ✅ Lister les étudiants
- ✅ Voir les détails d’un étudiant
- ✅ Modifier un étudiant
- ✅ Supprimer un étudiant
- ✅ Ajouter une photo

### 🎓 Gestion des filières

- ✅ Ajouter une filière

---

## 🛠️ Technologies utilisées

- PHP (PDO)

- HTML5 / CSS3
- phpMyAdmin
